# site/data/

Generated by `pipeline/`. **Never edit by hand**; change `curation/` or the generator and re-run it. Each file is a
classic script that assigns one section to `window.FGP_DATA` (`meta`, `items`, `recipes`, `mats`, `sources`,
`rules`, `roles`, `reference`, later `enchants` and `prices-default`), one record per line, under
`forever/` for the WoW: Forever dataset. See docs/data-model.md and docs/synthesis.md (D3, D5, D9).
