# Known problems / dead ends

- wago.tools answers Python's default user agent with 403; the pipeline sends its own User-Agent, keep it.
- Never read `~/.cache/wow-assistant/` (the private prototype's cache) and never commit a CSV or the listfile.
- The 69 Forever-new items without an ItemSparse row in 70205 (R1, open question S8) and the 51 stub-pattern
  recipes marked `unconfirmed` (R3) are the first thing to look for in the diff: if some gained rows, they are new
  content, and their derived sources land as `db` certainty with the badge. Do not curate their sources from
  memory; the orchestrator holds the private notes.
- A changed hash manifest for the same build would mean wago.tools re-exported hotfixed tables; for a new build the
  manifest is simply new. `--accept-new-hashes` is for the former case only.
